# Proposal

## Why

Нужна страница редактора склада `/[locale]/map-editor` с готовой раскладкой: шапка, тулбар, центральная область под карту, боковая панель, сводка и кнопки зума. Раскладка строится заглушками, чтобы позже в центральную область без переделки страницы встал виджет `warehouse-map`. Сейчас карта существует только в прототипе `apps/web/app/[locale]/prototype-map/WarehouseDemo.tsx`, который работает с `col/row` и захардкоженными данными.

## What Changes

- Страница редактора в слое `pages` (`pages/map-editor`):
  - шапка: кнопка «назад», название склада, статус сохранения и кнопка «Сохранить карту» (неактивная);
  - слева: тулбар инструментов (выбор, препятствие, станция, робот, ластик) с переключением активного инструмента; без логики размещения объектов;
  - в центре: слот под карту. Пока это заглушка, которая занимает всё свободное место и тянется вместе с окном. Позже в неё встанет виджет `warehouse-map`;
  - справа: панель с вкладками (добавить, объект, список, проверка). Пока это заглушки;
  - снизу: сводка (размер карты, число станций, роботов и препятствий) и контролы зума «–», «%», «+» и «вписать». Пока это только UI: у контролов есть пропсы для значения и колбэков, реальной логики зума нет.
- Моковые данные: фикстура склада `validWarehouseMap` в формате контракта `WarehouseMapBody` из `@robots/shared` (`packages/shared/src/fixtures/warehouse-map.ts`). Координаты берутся из полей `x`/`y` контракта, собственный формат (например, `col/row`) не вводится. Сводка внизу считается из этой фикстуры.
- **BREAKING (внутри web)**: прототип `WarehouseDemo.tsx` и маршрут `prototype-map` заменяются редактором; папка `app/[locale]/prototype-map/` удаляется.

Не входит в изменение:

- виджет карты на Konva (`widgets/warehouse-map`), зум колесом, перетаскивание, выделение объектов;
- превью карты (`map-preview`) для списков и карточек;
- Storybook;
- сохранение карты на сервер, редактирование объектов, подключение к API;
- изменение контракта `@robots/shared`.

## Impact

- **apps/web**: новый слайс `src/pages/map-editor`, маршрут `app/[locale]/map-editor/page.tsx`; удаление `app/[locale]/prototype-map/`.
- **packages/shared**: новый файл фикстуры `src/fixtures/warehouse-map.ts` и экспорт из `fixtures/index.ts`; контракт не меняется.
- **Зависимости**: новых зависимостей нет (`konva` и `storybook` в это изменение не входят).
- **Проверки**: RTL-тест страницы (vitest), `steiger` (FSD), ESLint, typecheck.
