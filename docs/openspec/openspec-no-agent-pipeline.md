# Пайплайн работы с OpenSpec (Терминал + Веб-чат ИИ)

## 1. Подготовка (один раз на проект)

- **Инициализация:** Выполните команду ниже, чтобы создать чистую папку `openspec/` без конфигов для агентских IDE.
  ```bash
  openspec init --tools none
  ```

## 2. Цикл разработки одной фичи

- **Шаг 1. Создайте задачу в терминале**

  ```bash
  openspec new change add-auth
  ```

- **Шаг 2. Соберите промпт для чата**
  Выведите в консоль готовые инструкции и шаблоны:

  ```bash
  openspec instructions proposal --change add-auth
  ```

- **Шаг 3. Сгенерируйте спеку в веб-чате**
  Скопируйте вывод из терминала в ChatGPT/Claude, добавьте описание фичи текстом (например, «Хочу вход по email и паролю») и попросите заполнить файлы (`proposal.md`, `specs/`, `design.md`, `tasks.md`).

- **Шаг 4. Сохраните и проверьте**
  Вставьте сгенерированный текст в соответствующие файлы внутри `openspec/changes/add-auth/` и проверьте синтаксис:

  ```bash
  openspec validate add-auth
  ```

- **Шаг 5. Напишите код**
  Реализуйте задачу по чек-листу из `tasks.md` самостоятельно или передавая файлы спецификаций в веб-чат.

- **Шаг 6. Заархивируйте фичу**
  Когда код готов и протестирован, обновите основную базу знаний (`openspec/specs/`) одной командой:
  ```bash
  openspec archive add-auth
  ```

> **Лайфхак для скорости:** Чтобы не запрашивать каждый файл по очереди, передайте в чат вывод команды `openspec instructions --change add-auth` целиком и попросите сгенерировать все 4 файла за один ответ.
