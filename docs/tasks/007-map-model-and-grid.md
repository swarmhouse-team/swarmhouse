# [MAP-007] Модель карты и компонент сетки

**Уровень:** middle frontend · **Время:** 2–3 дня

## Цель

Сделать основу редактора карты, которая не зависит от каркаса: модель карты с проверками и компонент отрисовки сетки на выбранной библиотеке. После мержа каркаса это переносится в монорепо, и задача редактора сводится к подключению API.

## Что сделать

**Модель карты** — чистый TypeScript, без React:

- типы: размер сетки, клетка, препятствие, станция (с названием), робот (с названием);
- функции: поставить, переместить, удалить объект;
- проверки из ТЗ: нельзя поставить два объекта в одну клетку, нельзя поставить робота в препятствие, нельзя выйти за границы карты;
- unit-тесты на Vitest.

**Компонент карты** на выбранной библиотеке:

- отрисовка сетки ~20 × 20 с препятствиями, станциями и роботами;
- масштабирование и перемещение по карте;
- клик по клетке, выделение объекта — через пропсы-колбэки, без логики сохранения;
- обновление одного объекта не перерисовывает всю карту.

## Результат

- Модель и компонент в отдельной ветке или песочнице, с тестами.
- После мержа каркаса — PR: модель в `packages/shared` (её используют и фронт, и бэк для проверки карты), компонент в `apps/web` в слое `entities/map` или `widgets/map`.
