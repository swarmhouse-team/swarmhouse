# [RESEARCH-005] OpenSpec и процесс работы с ним

**Время:** 1 день

## Цель

Понять, подходит ли OpenSpec (spec-driven разработка с ИИ-ассистентами) нашей команде, и если да — описать, как с ним работать.

## Что выяснить

- Что такое OpenSpec, как устроен (спецификации, предложения изменений, задачи).
- Как он работает с нашими ИИ-инструментами (Claude Code и др.).
- Как встроить его в наш процесс: задача → спецификация → ревью → реализация → PR.
- Что хранится в репозитории и как это ревьюить.
- Плюсы, минусы, сколько времени это добавляет к задаче.

## Результат

Документ `docs/adr/003-openspec.md`: решение «используем / нет», и если используем — пошаговый пайплайн для одной задачи. Пример: одна реальная задача проекта, проведённая через OpenSpec. Документ одобрен командой.
