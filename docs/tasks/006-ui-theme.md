# [UI-006] Тема UI kit по макетам

**Уровень:** junior frontend · **Время:** 1–2 дня

## Цель

Подготовить тему и список компонентов для `packages/ui`, чтобы после готовности каркаса их можно было сразу перенести, а фичи верстались в едином стиле.

## Что сделать

- Перенести из макетов цвета, шрифты, радиусы, отступы в тему shadcn/ui (CSS-переменные, светлая и тёмная тема). Можно собрать в tweakcn или вручную.
- Составить список компонентов из макетов: какие есть в shadcn/ui, какие нужно сделать самим (например, карточка склада, аватар пользователя).
- Проверить тему на нескольких компонентах shadcn в любом Next-проекте-песочнице.

## Результат

- Файл темы с CSS-переменными, готовый к переносу в `packages/ui`.
- Список компонентов в `docs/ui-components.md`.
- После мержа каркаса — PR с темой и недостающими shadcn-компонентами в `packages/ui`.
